# Rà soát routing và spacing — Nếp

## 1. Vấn đề đã tìm thấy

- Website dùng Next.js App Router + React + TypeScript; bốn màn hình chính vẫn chuyển bằng state nên URL không đổi.
- Lịch tự đăng và danh mục đã có URL riêng nhưng chưa dùng chung shell/context với các màn hình còn lại.
- Menu/header/footer và dữ liệu cần đặt ở layout chung để điều hướng không reset toàn bộ workspace.
- Margin/padding/gap rải nhiều số cứng không nhất quán, có quy tắc cũ dễ ghi đè khoảng đệm.
- Không thêm thư viện, không sửa API/SQL/nghiệp vụ đăng bài; giữ nguyên các khai báo màu, font, viền, bóng và animation.

## 3. Chuẩn routing và spacing

| Màn hình | URL |
|---|---|
| Trang chủ | chuyển hướng /san-pham/ |
| Sản phẩm | /san-pham/ |
| Thư viện ảnh | /thu-vien/ |
| Nội dung AI | /noi-dung/ |
| Thiết lập | /cai-dat/ |
| Lịch tự đăng | /automation/ (giữ link cũ) |
| Danh mục | /categories/ (giữ link cũ) |

Route group `(admin)` không xuất hiện trong URL. Layout giữ `AdminContext` và dữ liệu giữa các route trong nhóm. Các trang công khai và callback OAuth giữ nguyên link. Root redirect giữ kết quả OAuth để mở đúng phần kết nối.

- Thang token: `--space-4`, `--space-8`, `--space-12`, `--space-16`, `--space-24`, `--space-32`, `--space-48`.
- Gutter trang: 16px dưới 640px; 24px từ 640–1023px; 32px từ 1024px. Có max-width, căn giữa.
- Card: 16px mobile, 24px từ tablet; form chỉnh website dùng token tương ứng trong CSS Module.
- Button: 8px dọc × 16px ngang; button nhỏ 8px × 12px. Input: 8px dọc × 16px ngang.
- Cùng nhóm: gap 8–16px; khối lớn: 24–48px. Giữ nguyên thứ tự và kiểu bố trí hiện có.
- 238/210/180px của sidebar là kích thước bố cục được giữ từ bản gốc, đặt trong `--sidebar-width`; không làm tròn chúng thành spacing vì sẽ gây chồng sidebar/main.
- Có min-width:0, giới hạn chiều rộng và wrap cho nội dung dài; bảng rộng cuộn trong chính table container.

## 4. Checklist và bằng chứng

- [x] Có sáu URL riêng và sáu Next Link thật; không còn setView để chuyển màn hình.
- [x] Root redirect về /san-pham/; OAuth query được giữ khi chuyển /cai-dat/.
- [x] HTTP trực tiếp sáu route trả 200; tải lại từng URL trả 200.
- [x] HTML SSR mỗi route có đúng một menu aria-current=page, href khớp URL và chỉ một nav dùng chung.
- [x] Provider nằm ở layout dùng chung, không nằm riêng trong từng page.
- [x] Margin/padding/gap các CSS đã sửa dùng token; đối chiếu tự động xác nhận các khai báo màu/font/viền/bóng/animation/bố cục khác không đổi.
- [x] package.json, package-lock.json và các file SQL không đổi.
- [x] Production build thành công; 42 kiểm tra mục tiêu đã qua.
- [ ] Back/Forward bằng thao tác trình duyệt: đã dùng cơ chế chuẩn Next Link/router, chưa có kiểm thử trình duyệt thực tế.
- [ ] Xác nhận không tràn ngang, không sát mép tại 375/768/1280px: đã cấu hình responsive theo source, chưa xác minh hình ảnh bằng trình duyệt ở ba kích thước này.

HTTP reload là kiểm tra phục vụ route trên server, không thay thế kiểm thử tương tác/hydration trong trình duyệt. Không có công cụ browser QA tương thích cho bản nguồn trong phiên này; không ghi nhận các mục chưa chạy là đã đạt. Không đăng thử bài, không thay đổi dữ liệu hoặc deploy website thật.
